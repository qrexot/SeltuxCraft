# SeltuxCraft — Windows x64 · 08.11.2026

Бесплатный лаунчер для установки, обновления и запуска Minecraft-клиента на Rust.

## Изменения

Исправлен выбор Java Runtime при отсутствии поля `javaVersion.component` в манифесте: добавлены резервные соответствия для Java 8, 16, 17, 21 и 25. Это относится к подготовке и запуску версий, которым нужна Java; нативный Rust-клиент работает без JVM.

## Скачать

| Файл | Назначение |
| --- | --- |
| `SeltuxCraft.zip` | Лаунчер для Windows x64 с исходниками |
| `SeltuxCraft-Source.zip` | Отдельный архив исходников |
| `SHA256SUMS.txt` | Контрольные суммы |

Распакуйте `SeltuxCraft.zip` и запустите `seltux-launcher.exe`.

Сборка основана на Horizon. Лицензия MIT и уведомления об авторах находятся в исходниках. Лицензия Minecraft в комплект не входит.
