# SeltuxCraft

**Бесплатный Minecraft-клиент на Rust с собственным лаунчером.**

Нативный движок · Высокая производительность · Открытый код

[Релизы](https://github.com/qrexot/SeltuxCraft/releases) · [Telegram](https://t.me/seltux)

</div>

---

SeltuxCraft устанавливает, обновляет и запускает игровой клиент на базе Horizon. Нативный клиент работает без JVM и ориентирован на быстрый запуск и эффективное использование ресурсов компьютера.

## Возможности

- Одиночная игра и подключение к серверам.
- Управление версиями и настройками через лаунчер.
- Ресурспаки, шейдеры и совместимые модификации.
- Бесплатное распространение и исходный код по лицензии MIT.

## Windows

После публикации сборки скачайте **SeltuxCraft.zip** в разделе [Releases](https://github.com/qrexot/SeltuxCraft/releases), распакуйте архив и запустите **seltux-launcher.exe**.

| Файл | Назначение |
| --- | --- |
| `SeltuxCraft.zip` | Лаунчер для Windows x64 и исходники |
| `SeltuxCraft-Source.zip` | Исходники для изучения и сборки |
| `SHA256SUMS.txt` | Проверка целостности скачанных файлов |

В предоставленном архиве файл `Installer/seltux-launcher-setup.exe` идентичен основному лаунчеру.

## Производительность и проверка файлов

Клиент использует Rust и wgpu. Результаты FPS зависят от оборудования и настроек; отдельные замеры этой сборки пока не опубликованы. SHA-256 позволяет проверить целостность файлов и не заменяет проверку безопасности.

## Основа проекта

Основан на [Horizon](https://github.com/horizon-rust/horizon) — проекте Ludovic Marie и участников Horizon. Лицензии и сведения об авторах сохраняются в исходниках.

SeltuxCraft бесплатен; лицензия Minecraft в комплект не входит. Для режимов и серверов с проверкой лицензии нужен соответствующий аккаунт.

Неофициальный проект, не связанный с Mojang или Microsoft.
